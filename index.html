Capabilities

What we do, and where to see it

Each capability points to work above that you can open.

Software development

Web applications, installable phone apps (PWAs), APIs and PostgreSQL databases, in Python, JavaScript and TypeScript, and Go.

Evidence: TM Stone, Philalink, Mafisa, Pitso and Matsema.

Cloud and hosting

Deployment, domains, DNS, business email routing and managed PostgreSQL, set up on free or low-cost tiers so running costs stay low.

Evidence: this site, platforms.mendgroup.co.za and the client deployments above.

IT consulting

Turning a business's own prices and processes into a working system: costing and quoting, booking flows and record-keeping.

Evidence: the TM Stone quote calculator, which prices from the company's own list.

Security and data protection

Row-level security on the tables that hold people's identity, documents, agreements, payment records, disputes and reviews; only the public key in the code that runs on a phone; data export and erasure designed into the database; and automated test suites run before release.

Evidence: the platforms' database test suite, which runs against PostgreSQL 16 and checks what the database must refuse.

Local language, low-cost phones

Interfaces in Sesotho and English, apps that keep working without signal, and light pages, because mobile data is expensive.

Evidence: Mafisa, Pitso and Matsema; switch the language and go offline.

Data and automation

Data pipelines, scheduled jobs and analysis that turn scattered public information into a short list someone can act on.

Evidence: our own internal pipeline that collects and ranks Lesotho tender and funding notices.
